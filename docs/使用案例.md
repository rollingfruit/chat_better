一个用于人际沟通训练的 Agent 应用，我们以“模拟面试”为例。可以定义两个角色，选择他们能使用的工具。


#### **第一步：角色“附身”**

大家看，我们定义了两个 Agent：一个是经验丰富的面试官“老登”，另一个是求职者。每个角色都有独立的背景设定，比如性格、专业经验和面试目标。

点击启动，一场高度仿真的对话就开始了。

![chat_job-1角色初始化.gif](imgs/chat_job-1角色初始化.gif)

#### **第二步：动态工具与长期记忆**

在对话中，面试官 Agent 会根据求职者的回答，智能地调用不同的“面试工具”，比如发起**技术评估**、**行为面试**，甚至是**压力测试**。

同时，随着对话轮次增多，系统会自动压缩早期记忆，只保留关键信息，确保 Agent 能“记住”重点，不偏离主题。

![chat_job_2多种工具-记忆压缩.gif](imgs/chat_job_2多种工具-记忆压缩.gif)

#### **第三步：你的“上帝之手”**

这个功能非常实用——你可以随时暂停对话，给 Agent 下达指令，比如“请更深入地询问技术细节”。

Agent 会立刻根据你的建议调整对话策略，实现真正个性化的模拟训练。

![chat_job_3打断.gif](imgs/chat_job_3打断.gif)

#### **第四步：智能复盘报告**

面试结束后，系统会立即生成一份详细的评估报告，包含技能评分、亮点分析以及具体的改进建议，帮助你清晰地看到自己的优势和不足。

![chat_job_4总结报告.gif](imgs/chat_job_4总结报告.gif)
