## 🐛 故障排除

如遇到问题，按此顺序检查:
1. 访问 http://localhost:3001/test-api.html 测试API
2. 检查浏览器控制台是否有错误
3. 确认 `.env` 文件中的 `OPENROUTER_API_KEY`
4. 重启应用: `./run.sh`
